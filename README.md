# AI Pick

AI Pick은 다양한 AI 도구 중에서  
사용자의 목적에 맞는 AI를 추천해주는 서비스입니다.

사용자는 글쓰기, 리서치, 이미지 생성, 코딩 등  
사용 목적을 선택하면 해당 분야에 맞는 AI 도구를  
추천받고 탐색할 수 있습니다.

## 📌 주요 기능

### 1️⃣ 목적 기반 AI 추천
사용자가 AI를 사용하는 목적을 선택하면  
해당 목적에 맞는 AI 도구를 추천합니다.

예
- 글쓰기
- 리서치 / 검색
- 이미지 생성
- 코딩 / 개발
- 업무 자동화

---

### 2️⃣ AI 도구 탐색

100개 이상의 AI 도구 데이터를 기반으로  
사용자가 다양한 AI 서비스를 탐색할 수 있습니다.

각 AI 도구는 다음 정보를 제공합니다.

- 도구 이름
- 기능 설명
- 카테고리
- 태그
- 상세 정보
- 공식 웹사이트 링크

---

### 3️⃣ 검색 기능

AI 도구 이름, 설명, 태그를 기반으로  
원하는 AI 도구를 빠르게 검색할 수 있습니다.

---

### 4️⃣ 카테고리 필터

사용자는 카테고리를 선택하여  
특정 분야의 AI 도구만 볼 수 있습니다.

예

- 글쓰기
- 리서치
- 이미지
- 코딩
- 자동화
- 무료/프리
- 한국어 지원
