# 🚀 AI Pick : 맞춤형 AI 도구 추천 플랫폼

> **"당신의 목적에 꼭 맞는 AI를 10초 만에 찾아보세요."**
> 사용자의 니즈를 분석하여 가장 적합한 AI 서비스를 큐레이팅해주는 웹 애플리케이션입니다.

---

## 🔗 Live Demo
[👉 서비스 바로가기 (Vercel 배포)](https://wassup13.vercel.app)

---

## 📌 주요 기능 (Key Features)

* **맞춤형 큐레이션**: 사용자가 선택한 목적(글쓰기, 이미지 생성, 코딩 등)에 최적화된 AI 도구 추천
* **직관적인 UI/UX**: 복잡한 과정 없이 단 몇 번의 클릭으로 결과를 확인하는 사용자 중심 인터페이스
* **실시간 결과 피드백**: 데이터 기반의 AI 도구 리스트를 즉각적으로 렌더링

## 🛠 사용 기술 (Tech Stack)

* **Frontend**: React, TypeScript, Vite
* **Styling**: CSS (Modular/Component-based)
* **Deployment**: Vercel
* **Collaboration**: Git, GitHub (Project Structure Optimization 완료)
